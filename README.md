# Flash Nick Pro - Installation Guide (English)

## What is Flash Nick Pro?
Flash Nick Pro is a web application designed to create awesome nicknames for voice chat applications (Discord, TeamSpeak, Turkish voice chat apps, etc.).

## Features
- 20+ Google Fonts
- Text effects: Glow, Outline, Gradient, 3D
- 12 text animations
- Particle effects: Stars, Hearts, Snow, Fire, Confetti, Balloons, Flowers, Sparkles
- 35+ country flags with animations
- Image effects: Grayscale, Sepia, Invert, Brightness, Contrast, Blur, Vintage
- Inner text sparkles
- 8 preset templates
- 7 quick styles
- PNG and animated GIF export
- Save/Load designs
- History tracking
- Social sharing
- Light/Dark theme
- Mobile responsive

## Installation on Windows

### Option 1: Python (Easiest)
1. Install Python 3 from https://www.python.org/
2. Double-click `run.bat`
3. Your browser will open automatically at http://localhost:8080

### Option 2: Node.js
1. Install Node.js from https://nodejs.org/
2. Double-click `run-nodejs.bat`
3. Your browser will open automatically at http://localhost:8080

### Option 3: Manual
1. Save all files to a folder
2. Open Command Prompt (cmd.exe)
3. Navigate to folder: `cd path/to/flash-programi`
4. Run: `python -m http.server 8080` (or use Node.js)
5. Open in browser: http://localhost:8080

## Files Included
- `index.html` - User interface
- `style.css` - Styling and animations
- `app.js` - Main application logic
- `gif.js` - GIF export library
- `gif.worker.js` - GIF processor
- `run.bat` - Python launcher
- `run-nodejs.bat` - Node.js launcher
- `setup-check.bat` - System requirements checker

## System Requirements
- Modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection (for Google Fonts on first load)
- 100MB free disk space
- Python 3 OR Node.js (one of them required)

## Getting Started

1. **Customize Your Nick**: Use all the options in the left panel
2. **Quick Styles**: Click the style buttons at the top for quick presets
3. **Add Background**: Upload an image - it won't disappear when you apply templates!
4. **Add Effects**: Choose animations, particles, and sparkles
5. **Add Flags**: Include country flags with wave, rotate, slide, or bounce animations
6. **Download**: Export as PNG or animated GIF
7. **Save**: Save your design for later use

## Troubleshooting

### Page doesn't load
- Refresh your browser (F5)
- Try a different browser
- Check your internet connection

### Download buttons don't work
- Make sure JavaScript is enabled
- Check browser console (F12) for errors

### Animations are slow
- Reduce particle density
- Close other programs
- Restart your computer
